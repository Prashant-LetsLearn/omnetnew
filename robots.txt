# NOTE: A crawler obeys ONLY the most specific User-agent group that matches
# it — it does not also inherit the "User-agent: *" rules. So every allowed
# group below repeats the same private-path Disallow list.

# Tracking parameters (utm_*, gclid, fbclid) are deliberately NOT blocked:
# blocking them stops Google from seeing the canonical tag on those URLs and
# can cause "Indexed, though blocked by robots.txt". Every page carries a
# self-referencing canonical, which consolidates parameter URLs instead.
# ════════════════════════════════════════════════════════════════════════
